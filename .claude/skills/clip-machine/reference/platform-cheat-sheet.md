# The Per-Platform Spec Cheat-Sheet — TikTok · Reels · Shorts

The ship from "One Video → Everywhere". Everything the machine (or you)
needs to make one clip native on each platform. Same video file, three
different treatments.

## The one table

| | TikTok | Instagram Reels | YouTube Shorts |
|---|---|---|---|
| **Canvas** | 9:16 · 1080×1920 | 9:16 · 1080×1920 | 9:16 · 1080×1920 |
| **Sweet-spot length** | 21–60s (up to 10 min allowed; short wins) | 30–90s (≤90s keeps full Reels-tab reach) | ≤60s classic · up to 3 min allowed |
| **Caption text** | Conversational hook + 3–5 niche hashtags; front-load the idea | First ~125 chars show before "…more" — the hook lives there | Barely shown — put the value in the TITLE (≤100 chars) |
| **Cover / first frame** | Selectable cover frame + big cover text (profile grid navigation) | Grid shows a 1:1 CENTER crop — title text must live in the center square | Pulls a frame — make frame 0 the cover (no intro card) |
| **Safe zones** | Bottom ~20% and right rail = UI; keep captions clear | Top ~14% + bottom ~20% = UI | Bottom ~18% = title/controls |
| **Native rules** | Native upload only; `privacy: PUBLIC_TO_EVERYONE`; flag AI content when it applies (`isAigc`) | Native Reel (not a link); mixed carousels allowed but Reels reach > photo reach for video | `#Shorts` in title still helps discovery; `categoryId` + `madeForKids` required via API |
| **Burned captions** | Yes — most watch muted | Yes | Yes |
| **Same caption 3×?** | ❌ Never | ❌ Never | ❌ Never |

## The five laws that travel across all three

1. **Native or nothing.** Platforms bury link posts and reward native
   uploads. Upload the file, never the link.
2. **Cover = frame 0, video starts at frame 1.** A 1-second title card at
   the start reads as a static post and kills retention. The cover IS the
   first frame; by the next frame the person is already talking.
3. **Finish the point.** A 75-second clip that completes its idea
   outperforms a 30-second fragment. Don't cut for length, cut for
   completeness.
4. **Word-synced burned captions** inside the safe band. Sourced from the
   word-level transcript, never approximated.
5. **End every clip pointing home.** End-card or caption line back to the
   long video — the clip's job is the click to the source, not just the view.

## Posting cadence

Space clips 1–2 per day. Nine clips in one afternoon competes with itself;
nine clips across a week is a content calendar.
